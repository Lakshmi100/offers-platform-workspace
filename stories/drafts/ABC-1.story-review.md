## Nice to know
- Process: the story is still a draft (`needs-approval`, "not yet an issue"), and `Lakshmi100/abc-bank` has no issues. `AGENTS.md` says every story gets the `approved` label before `/story` runs. FND-2, FND-3 and FND-4 will also be `abc-bank` issues, so the real issue number, and so the key, may not be ABC-1. When approving, also confirm or relabel the "To confirm" decision.
- R6 is verified only by ABC-5's load. ABC-1 can be done with sizing untested, and a later resize changes this story's root. ABC-5 may want to say so too.
- AC8 relies on the Tagging API, which sees only tagged resources. Things AWS may create for the database without Terraform's tags could slip past it. Examples: a CloudWatch log group that RDS creates itself for log exports, or retained automated backups (listed by `describe-db-instance-automated-backups`, not `describe-db-snapshots`). A secret in its deletion recovery window could also make the result ambiguous. AC7's "every resource … has the four cost tags" covers what Terraform manages.
- AC8 "the FND-2, FND-3 and FND-4 resources are unchanged" does not name the check. One option is `terraform plan` in those roots showing no changes, as FND-1 AC13 does. Another is FND-3 AC8 / FND-4 AC8 style existence checks.
- Encryption in transit (TLS for the `psql` connection) is not stated. `AGENTS.md` does not require it, and recent RDS PostgreSQL versions enforce SSL by default.
- The engineer's database user (name, privileges in `core_banking`) is unspecified. AC2 only needs it to connect, and the story leaves the schema owner to ABC-2.
- R7 "It is for administration only" names no reader. Only the administrator and engineering roles exist, so this probably changes nothing.
- Each session destroys the database with no snapshot (AC8), so ABC-5's SF10 data is reloaded every session. This matches "exists only during working sessions"; load time is ABC-5's concern.
- FND-5's context still calls ABC-1's cost criterion "AC9"; it is now AC10.
- The PostgreSQL major version is not pinned (AC2 accepts any DMS-supported one). Consider matching Spike 2 (CDC) if it runs.
- `AGENTS.md`: "The first story that adds code must add a `Makefile`". FND-2/3/4 come before ABC-1 in `abc-bank`, so this falls to one of them; if ABC-1 lands first, it must add it.
